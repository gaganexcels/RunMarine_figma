ANIMATION & INTERACTION — GLOBAL RULES
—————————————————————————————————

- Scroll entry: opacity 0→1 + translateY(24px→0), 
  500ms ease-out. Clean. No bouncing.
- Hover on all interactive elements: 200ms minimum transition
- Page transitions: smooth fade, not slides or flips
- Custom cursor: small refined dot that follows with slight lag, 
  expands slightly on hoverable elements
- Loading screen: white canvas, thin horizontal line draws 
  across like a horizon, company name fades in letter by letter, 
  clean dissolve into homepage. 2.5 seconds max.
- Reduce motion: respected for accessibility 
  (prefers-reduced-motion media query)
- No looping animations beyond 3 cycles unless user-triggered
- Buttons: hover state must feel tactile — 
  subtle scale or fill shift, never aggressive

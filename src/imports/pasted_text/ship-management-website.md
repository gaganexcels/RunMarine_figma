GLOBAL ANIMATION RULES
—————————————————————————————————

- All page transitions: Fade + slight upward movement (not jarring slides)
- Scroll animations: Use Intersection Observer — elements enter with 
  opacity 0→1 + translateY(30px→0) over 600ms ease-out
- Hover states: All interactive elements have a 200ms transition minimum
- No animation should autoplay for more than 3 loops unless user-triggered
- Reduce motion media query respected for accessibility
- Cursor: Custom cursor — a small gold circle that follows mouse with 
  slight lag (magnetic feel), expands on hovering over links/buttons
